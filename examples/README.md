# 示例

这里的东西是给你照着自己建角色用的 —— 装上 App 之后里面是空的，一个角色都没有。

## 怎么用

1. 把 `示例角色卡.json` 传到手机上（数据线 / 微信文件传输 / 网盘都行）
2. 打开 App → 左上角 ☰ → **全部设置** → 往下找到「角色卡」
3. 点 **导入角色卡（.json / .png）** → 选这个文件
4. 回到角色列表，她就在那儿了

导入是**新建**一个角色，不会覆盖你已有的。

## 这张卡在示范什么

`description`（在 App 里叫「人设」）是唯一真正重要的字段。示例卡把它分成了几块：

| 块 | 回答的问题 |
|---|---|
| 她是谁 | 身份、年龄、现在在干什么、过去有什么（以及什么不愿提） |
| 性格 | 她怎么反应，包括**不好的一面** |
| 说话方式 | 句子长短、口头禅、被问到不想答的事怎么办 |
| 在意的事 | 具体的、能触发情绪的细节 |
| 雷区 | 明确不要写的东西 |

**越具体越像。**「温柔善良」这种词她演不出来；「别人把书折了角她会当场沉默」她能演。

`first_mes`（开场白）里放**动作**，不要只放台词 —— 一句「（踩着梯子没回头）自己找地方坐吧」比「你好，欢迎光临」有用得多。

## 世界书

示例卡里带了两条，示范两种用法：

- **按关键词触发**：聊到"旧书店""店里"才注入店面的样子
- **一直生效**（\`keys\` 留空）：整体基调，每轮都发

世界书是**按需注入**的，所以可以写得比人设长 —— 不触发就不花 token。

## 自己写

在 App 里：角色列表 → 右下角 ＋ → 选「空白角色」→ 开始写。

写的时候不用管格式，几段纯文本就行。上面那五块只是我建议的分法。
