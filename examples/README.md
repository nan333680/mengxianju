# 示例

这里的东西是给你照着自己建角色用的 —— 装上 App 之后里面是空的，一个角色都没有。

## 里面有什么

| 文件 | 是什么 | 示范什么 |
|---|---|---|
| `示例角色卡-祝小满.json` | 原创角色（便利店店员，晚上写小说） | 一个完整的原创人物 + 5 条卡内世界书 |

## 怎么用

**导入角色卡**

1. 把 `.json` 传到手机上（数据线 / 微信文件传输 / 网盘都行）
2. 打开 App → 右上角 ⚙ → **我的设置** → 往下找到「角色卡」
3. 点 **导入角色卡（.json / .png）** → 选文件
4. 回到角色列表，她就在那儿了

**导入世界书**

1. 同样传到手机
2. 右上角 ⚙ → **世界书** → **导入世界书文件**

导入是**新建**，不会覆盖你已有的东西。

## 世界书怎么分层

世界书分两种：**卡内世界书**（跟着角色走）和**全局世界书**（按主题分成几组，
每组十几条，**聊到才注入**，不触发就不花 token）。

两者可以**同时用**：角色自己的设定放卡内，整个世界观的常识放全局。

## 写人设的要点

`示例角色卡-祝小满.json` 的人设分成五块：

| 块 | 回答的问题 |
|---|---|
| 她是谁 | 身份、年龄、现在在干什么、过去有什么（以及什么不愿提） |
| 性格 | 她怎么反应，包括**不好的一面** |
| 说话方式 | 句子长短、口头禅、被问到不想答的事怎么办 |
| 在意的事 | 具体的、能触发情绪的细节 |
| 雷区 | 明确不要写的东西 |

**越具体越像。**「温柔善良」这种词她演不出来；「她给你留一串关东煮，留到打烊还装作是卖剩下的」她能演。

`first_mes`（开场白）里放**动作**，不要只放台词 —— 一句「（趴在收银台上写东西，听见门响，笔没停，先出了声）又是你啊。」比「你好，欢迎光临」有用得多。

## 自己写

在 App 里：角色列表 → 右上角 ＋ → 选「空白角色」→ 开始写。

写的时候不用管格式，几段纯文本就行。上面那五块只是建议的分法。
