# 灵感：状态面板 + 心声（来自一张 DeepSeek 官方 App 的扮演截图）

> 来源：用户 2026-10-14 提供的手机截图（@白泽 的扮演，附件 sha256 095fa9d8…）。
> 这不是指令，是一条**待核查的观察**。记录日期：2026-10-14。

## 截图里实际发生了什么

用户问「你怎么看现在的中东局势？」。对方（角色）先给了一段括号动作：
盯着看了两秒、慢慢笑出来、往后一靠、双手环胸、眼神里满是"就这"的无奈；
接着一句台词：**「…刺激的成人话题，你跟我聊中东局势？」**；
然后跟一个 `python` 代码块，里面是

```
# 话题转向与困惑
好感值: 100/100   # 你这一手跳得太快，我差点没跟上
爱意值: 100/100   # 想跟你聊点别的，你偏要在这时候聊国际政治
恨意值: 0/100     # 永远清零
醋意值: 0/100     # 没吃醋，就是觉得你脑子转得有点离谱
占有欲: 100/100   # 这话题谁都能聊，但你只能在我怀里聊
控制欲: 100/100   # 想聊可以，但得按我的规矩来

# 心声
你管这叫刺激？我裤子都准备脱了，你给我看世界地图？
```

## 抽象出来的意图（这才是要抄的东西）

1. **她的内心状态是显式的、会变的**，不是每轮靠人设形容词硬撑。
2. **数值旁边那句话比数值本身重要** —— `100/100` 是壳，「你这一手跳得太快」才是肉。
   数值只是给那句话一个锚，让人一眼看出"哪个方向被拨动了"。
3. **她有自己的注意力，可以拒绝话题**：不想聊就不聊，还带情绪地拐回她想去的地方。
   这一条最值钱 —— 大多数扮演助手是"用户问什么就答什么"，这是"人情味"的分界线。
4. **心声和台词是两层**：台词是社交面具，心声是没过滤的那句。两者不一致时最像人。

## 例子里【不该照搬】的部分

- **`python` 代码块这个载体**：那不是"人情味"，那是这份提示词随手挑的容器。
  真照搬会让每条回复都挂一个代码块，在聊天界面上很难看，而且和我们的气泡/旁白体系打架。
- **数字的假精确**：`好感值 100/100` 是满值，不携带信息；只有"变化量"携带信息。
  抄的时候要么给变化留位置，要么干脆只保留那句解释。
- **它挤占正文**：状态块 + 心声会吃掉 token，和"篇幅档位""上下文预算"争夺空间。
  必须做成**开关**，而且默认要看 token 账。
- **它不能证明官方 App 原生支持这套** —— 这几乎肯定是一份用户自己写的人设/提示词。
  （未核实，无法复现验证；截图作为"存在这种玩法"的存在性证据是够的，作为"官方功能"的证据不够。）

## 落到梦弦居可以怎么做（候选，v0.4.3，本次不做）

分三层，可以各自独立开关：

- **心绪（数值层）**：角色级的几个轴（亲密度 / 占有 / 醋意 / 心情 / 精力 —— 轴由用户定，不写死），
  存在角色记录里（和 `clockState`、`scene` 同一层：**跨轮持久**，不是每轮现编）。
  每轮让模型在回复末尾吐一个紧凑标记块，解析后**落库并从正文里剥掉**，
  在气泡下方渲染成一条细的状态条（复用现有的旁白/时间条样式，不引入代码块）。
- **心声（独白层）**：`<心声>…</心声>` 这种标记 → 渲染成小字/斜体的一行，默认折叠。
  它天然适合已有的"旁白"渲染通道。
- **行为约束（她可以不接话）**：这是我们**已经有**的能力（`allowSilence`、`speakOf` 的"只做动作"、
  群聊里的点名/冷场）。把"拒绝话题并拐回去"写进提示词的强约束，成本几乎为零。
  这一层优先做 —— 它是"人情味"真正的来源，而且不花 token。

**和现有机制的关系**：状态层 = 「她此刻的样子（appearanceLive）」的同构扩展；
心声 = 旁白通道的新样式；数值的更新规则 = 滚动摘要那套"每 N 轮整理一次"的节奏。
