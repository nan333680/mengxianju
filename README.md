# 梦弦居 · 使用说明

一个安卓端的 AI 角色扮演 App。聊天是「发生」，一场戏是「成篇」—— 同一套角色、设定和记忆，两条路。
纯本地、无账号、自备 API Key，直连你选的服务商。

**聊**：多角色、**群聊**（几个人一起聊，轮流或点名）、世界书（角色组 / 单独角色两层）、
长期记忆与滚动摘要、剧情时间线、**剧情卡**（这一段往哪走，按拍推进，把方向拽住）、
**非破坏分支**（从这里重聊、切回另一个走向，旧的那条不删）、
发图识图、联网搜索（可选后端）、描写控制（上限 × 驱动力双轴）、视角锁定。

**写**：**开一场戏**（演员 / 导演 / 观众三种在场方式，分拍写成一篇）、
**书架 / 阅读页**（全屏衬线、三种主题）。

**共通**：Character Card **V2 / V3** 导入导出（`.json` / `.png` / `.charx`）、自动备份。

**兼容酒馆（SillyTavern）**：世界书、角色卡、聊天记录（`.jsonl`）、酒馆正则、预设文件
都能接过来 —— 见下文「三、主要功能」里的「世界书」「酒馆（SillyTavern）的文件」两节。

> 这份说明是按 v0.5.2 校准的。逐版改了什么看 [CHANGELOG.md](CHANGELOG.md)。

## 一、安装

APK 在发布页下载：

https://github.com/nan333680/mengxianju/releases/latest

历史版本见同一个发布页。

1. 从发布页下载 APK 到手机
2. 用手机的文件管理器点开这个 APK
3. 系统多半会拦一下，按提示放行：
   - 提示"未知来源"→ 去 **设置 → 应用 → 特殊应用权限 → 安装未知应用**，允许你正在用的文件管理器
   - 弹出"未经安全检测 / 可能存在风险"→ 选 **仍要安装**
   - 被"纯净模式"之类的功能挡住 → 在设置里临时关掉
4. 装好后桌面会出现「梦弦居」图标

> ⚠️ 装不上基本都是手机自带的安全管家在拦，不是 APK 有问题。
> 各家叫法不一样（未知来源 / 外部来源 / 纯净模式），找到「安装未知应用」这类权限放行即可。

## 二、首次配置

装完是**空的**（不预置任何角色），要自己做两件事：填 API Key、建一个角色。
App 顶部会有引导条提示。

1. 点左上角 **☰** → **我的设置** → **接口**
2. 在「服务商」里选一家，填上对应的 API Key
3. 回到聊天页，点左上角 **☰** → **角色列表** → 右上角 **＋**，建你的第一个角色

> **不知道人设怎么写？** [`examples/`](examples/) 里有两张可以直接导入的示例卡：
> 一张讲结构的最简卡，一张完整的原创人物（附 5 条卡内世界书）。
> 导入步骤与写人设的要点见 [examples/README.md](examples/README.md)。

选一家就会自动填好 Base URL 和模型名，之后都能再手改：

| OpenAI | |

### 默认参数

下面是选 DeepSeek 时的初值，换服务商会跟着变：

| 项目 | 默认值 | 说明 |
|---|---|---|
| 对话模型 | `deepseek-flash` | **自带看图能力** |
| 识图模型 | `deepseek-flash` | 同一个模型就够 |
| Base URL | `https://api.deepseek.com` | 选完服务商自动填 |
| 推理强度 | `low` | 见下方说明 |
| 温度 | 1.0 | 低=沉稳，高=活泼 |

### 推理强度 off / low / high / max

- **off** — 完全关闭思考，回复最快（内部映射为接口的 `none`）
- **low** — 聊天推荐，略微思考
- **high / max** — 更聪明但明显变慢，日常聊天用不上

## 三、主要功能

### 角色
- 点左上角 **☰** 进角色列表，**＋** 新建角色
- 每个角色有：名字、头像、人设、开场白
- 角色列表里点 **✎** 编辑

### 聊天
- 底部 **🖼** 发图片 → 她看得懂（要求所选服务商的模型支持看图）
- 回复是流式打字机效果
- 生成中可点 **停止** 中断
- Enter 发送，Shift+Enter 换行
- **长按消息**弹出的菜单按这条消息是什么来给：**复制文字**；你发的可以**编辑重发**；
  她发的可以**朗读这条**（要系统装了中文语音）、**重新生成**（最后一条）、**从这里重聊**（更早的）；
  归档区的可以**取消归档**。她还在打字时不给「编辑重发 / 删除这条 / 重新生成 / 从这里重聊」这四项，
  按「停止」之后再用

### 分支（另一条走法）

长按她的一条回复 → **从这里重聊**，会从那条重新生成。原来那段**不删**，成了另一条走向。

- 生成完之后，这条消息的菜单里会多一项 **切到另一个走向（N 个）**
- 点它就换到另一条线上往下接，旧的那条还在库里，随时切得回来
- 切过去时，那条线上被归档的消息会自动放回来（不然屏幕是空的）
- 备份和导出照常包含所有走向，不只当前这条

### 时间（第几天 · 几点）

聊天栏顶上那条「秋 · 第 3 天 · 傍晚 · 晴」是**剧情里的时间**，不是手机时间；消息底下也会标。

- **手动调**：点时间条直接改天数 / 时段 / 天气
- **跟现实走**（**☰ → 全局设置 → 时段划分**）：时间按手机真实时钟走，第 1 天从你打开开关那一刻算，季节跟着月份变。开着的时候时间条缩成一行只读小字，想手动调先关掉
- 打开「**显示具体时间**」后精确到几点几分，记忆也能记到「第几天几点」
- 每个时段对应几点可以自己划（默认按早/上午/中午/下午/傍晚/夜/深夜）

### 表达方式（角色编辑页）

| 设置项 | 说明 |
|---|---|
| **回复长度** | 很短 / 短 / 中等 / 长 —— **只管她开口说出来的话** |
| **非对话描写** | 关闭 / 少 / 中 / 丰富 —— **只管括号里的动作神态**，和上面那个是两个独立的上限 |
| **描写详细程度** | 规定括号里**必须写成什么形状**（动作链 / 三段式 / 感官锚点…），和上面那个「上限」是两回事，两者互不覆盖 |
| **表达预设** | 点一下，把上面这几项一次填好 |
| **叙事视角** | 第一人称 / 第二人称 / 第三人称等，可锁定 |
| **颜文字频率** | 关闭 / 偶尔 / 适中 / 经常 / 总是 |
| emoji 频率 | 独立控制，和颜文字分开算 |
| 分段发送 | 一条长回复拆成几条，更像真人 |
| 打字延迟 | 模拟真人打字速度 |
| 使用「……」表现迟疑 | 模拟犹豫 |

> **颜文字频率不是简单塞提示词**：程序会统计最近 8 条消息的实际使用率，和目标频率做负反馈调节，避免她一会儿狂发一会儿完全不发。

### 剧情卡

聊天页顶部那个「**剧情**」按钮里，写**这一段往哪走** —— 不是台词，是方向。

- **想往哪走**：一句话说清这段最后要走到哪儿。不用写台词，也不用写大纲 —— 写方向，她自己往下演
- **不能发生什么**：一行一条，写你最不想在这段里看到的事（什么题材都行，群聊也一样用）
- **几拍**（最多 12 拍）：把这段拆成几个阶段，每一拍写「要到 / 卡在 / 终点」
  - **要到** —— 这一拍结束时该发生的事
  - **卡在** —— 中间挡着的是什么
  - **终点** —— 这一拍**结束之后**才该发生的事

> **每一轮只把当前这一拍交给她。** 后面几拍的终点她看得到，但提示词里明写「这一轮别给它」——
> 实测 8 轮对话下来，第 1 拍的终点一次都没被提前演出来。
> 这是它和「这一轮想怎么演」最大的区别：后者管**怎么写**，剧情卡管**事往哪发生**，而且会拽住她不让一步跨到终点。

- 拍上点「设为当前」换拍；演够了点「这一拍演完了 →」推进，**推进立刻落盘**，推完 12 秒内可撤销
- **关掉剧情不会删内容**，但它是一个真的暂停态：关掉的卡存回去仍然是关着的，下次打开顶上会挂一条黄条，点右边的「重新开启」才让它重新进提示词
- 拍的「演了几轮」按真正生成过的轮数算，重新生成 / 续写不重复计数
- 每张卡跟着角色走，换角色不串味
- 剧情卡和「这一轮想怎么演」可以同时用：方向定骨架，临时指令定这一轮的写法

### 开一场戏（小说层）

抽屉里「**✒ 写一场戏**」开一场，写完进「**📚 书架**」。它和聊天是两条路：聊天是「发生」，一场戏是「成篇」，书架是「回看」—— 但共用同一场戏里的同一个人。

- **两档长度**：短 300–600 字（1 拍）、中 600–1200 字（1–2 拍，第二拍必须有个小转折）。**字数是上限不是任务**：事没写完可以继续，事写完了就停
- **三种在场方式**（开戏时选一次）：**演员**（你在场，自己写自己的话和动作，她不替你说话）、**导演**（你不在场，正文里不出现「你」，你敲的是导演指令）、**观众**（你在场，允许她代笔）
- **开戏要写的**：地点 / 时间 / 天气 / 这一场结束时要和开始的时候不一样（一句）/ 不能出现什么（一行一条）。不写台词，不写大纲
- **中场先分拍**：会先给 1–2 拍的草案，可以「重新分拍」或「按这个写」，确认后逐拍写正文
- **正文不进聊天记录** —— 聊天里的记忆、归档、分支都不会被它污染；反过来删一场戏也永远不碰聊天
- **临时人物**：只在这一场里出现的人，五行小卡（名字 / 身份 / 外表一句话 / 他想要什么 / 他瞒着什么），不进角色列表、不进长期记忆
- **质量闸门**：字数、这一场有没有真的变化、有没有出现没登记的名字、有没有「作为 AI…」这类收尾。不合格**只自动重试一次**，再不过就把原因摆出来让你选「按这个原因重写 / 继续 / 就这样」
- **阅读页**：全屏滚动、衬线正文、没有气泡和时间戳。点屏幕中间呼出控制层（字号 / 主题 / 重写这一段 / 继续这一段 / 删除这场），三种主题暗色 / 米色 / 浅色
- **删除**：整篇进回收站（30 天内可找回）/ 删一拍 / 去掉这场里的人物（台词可转旁白）/ 断开与聊天的关联

> 硬规则：**小说删除永远不碰聊天，聊天删除也不碰小说，清空聊天不删戏。** 删角色时会问一句「保留作品 / 一起删」，默认保留。

正文里怎么称呼你，由「我的设置 → 称呼」（名字 / 旁白怎么指你 / 你在这个故事里是谁）和每个角色编辑页里的「她怎么看你」决定；两处都不填，就还是老样子。
### 世界书

设定不一定要全塞进人设 —— 世界书是**聊到才注入**的，不触发就不花 token。

- **两层**：**角色组**（按主题分组，一组十几条，可指定对哪些角色生效）和**单独角色**（只对某一个角色）
- 每条有自己的**触发词**，命中才注入；也可以设成「一直生效」（进每轮的固定前缀）或「临场提醒」
- 角色卡里自带的世界书（`character_book`）也会一起导进来

### 酒馆（SillyTavern）的文件

从酒馆搬过来的人，手上那几个文件都能接过来：

- **世界书** —— `{ "entries": { "0": {…} } }` 这种酒馆导出的默认形态可以直接导入（`entries` 是对象或数组都收）；
  裸数组文件、`{ name, entries }`（名字当组名）、单条对象也都收（v0.4.2.1）。
- **酒馆世界书的"生效时机"字段真的照做**（v0.4.2.1）：二次筛选（`selective` + `keysecondary` +
  `selectiveLogic` 四档）、概率 `probability`、按对话深度插入（`position: 4` + `depth`）、
  插入顺序 `order`、区分大小写、整词匹配。
  ⚠️ 整词匹配**只对纯 ASCII 触发词生效** —— 酒馆官方文档明确警告"整词匹配对中文日文有害"，
  含中文的触发词一律还是子串匹配。
  ⚠️ **读不懂触发条件的条目会被标「待确认」**：落库了但**不注入**。世界书页会显式报数并列出原因，
  逐条处理 —— 点「一直生效」、点进卡片改触发词、或用不上的点「丢弃」。
  这样处理是因为**猜错比不导入更糟**：你以为设定生效了，实际触发时机全错，还不报错。
- **角色卡** —— JSON / PNG / **CHARX**（`.charx`）都能【导进来】，卡内世界书一并进来（导出是 JSON / PNG 两种）。
- **老格式的卡也认**（v0.4.2.1）：TavernAI / Pygmalion 那一代（`char_name` / `char_persona` /
  `world_scenario` / `example_dialogue` / `char_greeting`）、带 BOM 的 JSON、扩展名是假的
  （内容其实是 JSON 却叫 `.png`）—— 一律**按文件头**判断，不看扩展名。
- **备选开场白**（v0.4.2.1）：卡里的 `alternate_greetings` 会存下来，**长按聊天里那条开场白**可以一条条换。
  卡里的 `tags` 也存下来并写回导出，不再是"读了就扔"。
  V2 和 V3 都认：V3 的昵称、立绘（`assets`）、群聊开场白、`@@` 装饰器、
  `secondary_keys`、`use_regex` 都会读进来；卡里的 `{{char}}` / `{{user}}` 这类宏在导入时就展开。
- **聊天记录** —— 酒馆导出的 `.jsonl` 可以导入（☰ → **我的设置** →「酒馆聊天记录」）。
  角色卡能重下、世界书能重下，**聊天记录没了就是没了**，所以这一件尽量接住。
  导入前会先告诉你里面有多少条、谁在说话；导进哪个角色由你选，**不猜**。
- **酒馆正则** —— 卡或预设里带的正则会收进「酒馆正则」，逐条开关。
  它们**只改两处副本**：送进模型的提示词、屏幕上显示的字。**存档原文一个字都不动** ——
  关掉就能看到原样，删掉也不会丢任何聊天记录。
- **预设文件** —— ☰ → **我的设置** → 往下找到「酒馆预设」，可以看它里面有哪些提示词段和正则。
  预设本身**不会自动生效**：正则要你点「收进来」，某一段提示词可以点「转成世界书条目」或
  「转成人设补充」—— 要哪一段由你挑。

### 群聊

- ☰ → 角色列表 → 底部「**新建群聊**」，选两个人以上，起个名字
- 群就是"成员是一组人的角色"：**它有自己的聊天记录、自己的剧情时间、自己的一份长期记忆**
- 顶部那排名字就是**在场的人**，**亮着的那个是这一轮该说话的人**
  - **轮流**（默认）：按你选人的顺序一个个来
  - **点名**：在话里写 `@名字` 或 `名字：`，就那个人答
  - 直接**点顶部某个名字**，下一轮就轮到她
- 每条回复的气泡上会写明**是谁说的**（单聊不显示，看着更干净）
- 群会读**每个成员各自的世界书**；但成员**各自的长期记忆不参与群聊** ——
  群用的是群自己那份共享记忆。这是有意的：把甲的私事塞进乙的嘴里，比"她们不知道"更糟

### 联网搜索

默认**关**。开着的时候也**只有你在话前面写 `/搜` 才会联网**，平时的聊天不受影响、不花这份钱。

- **☰ → 全局设置 → 联网搜索**：总开关、搜索用哪家、搜索 API Key
- 搜索后端默认 **Tavily**（注册免费、每月 1000 次、不用绑卡），也可以换别的
- 只想给某几个角色开：进角色编辑，把「联网搜索」设成**强制开**（跟随全局 / 强制关同理）
- 搜了之后回复的气泡上会标记用到了搜索；没搜成也会标「没搜成」，不会假装查过

### 记忆

- **长期记忆**打开后，聊得久了会自动把对话总结成要点记住
- 历史太长会被压成**滚动摘要** —— 不然迟早顶到模型的上下文上限，她就从"记得"变成"报错"
- 记忆可以带**有效期**（「第 5 天之后不再记着」），过了就不往提示词里放，但不会删
- 记忆会自动**去重 / 整理**，省出来的位置给新的事
- **查看 / 编辑她记得的事** → 能手动增删改；群聊用的是群自己那份共享记忆（见上文「群聊」）

### 数据

- **导出全部数据** → 备份角色和聊天记录（不含 API Key，可以放心发出去）
- **导入数据** → 恢复；同 id 以导入的为准，不同 id 追加，不会一次冲掉你现有的
- **自动备份**：按选定频率往手机存储写一份明文 JSON，留最近 7 份，放在「**文档 → 梦弦居备份**」，
  所以能活过卸载和「清除数据」。频率（每天 / 每 3 天 / 每 7 天 / 关）和当前文件路径在「**我的设置 → 数据**」里能看能改，
  还能点「检查我最近那份备份能不能用」真读一遍
- **角色卡**（我的设置 → 角色卡）：单张卡的导入导出，`.json` / `.png` / `.charx`，Character Card **V2 / V3** 都认。
  它和「导出全部数据」是两条路 —— 一个是整机备份恢复，一个是单张卡搬来搬去
- 清空记录 / 清空全部数据

## 四、常见问题

**Q1 · 发消息没反应 / 报错？**
先检查 **☰ → 我的设置 → 接口** 里的 API Key 填了没、账户有没有余额。

**Q2 · 她说话不像她？**
进角色编辑，改「人设」那一段。写得越具体，演得越准。

**Q3 · 想要完全不要颜文字？**
**☰** → 角色列表里点 **✎** → 展开「表达方式」→ 颜文字频率选 **关闭**。
这一项每个角色各有一套；想一次改掉所有角色，勾上那一页底部的「覆盖全局设定」再保存。

**Q4 · 聊天记录存在哪？**
存在手机本地（IndexedDB），不上传任何服务器。卸载 App 会一起删掉，重要的话先导出。

- 系统云备份（Google Drive / 厂商云）从 v1.21.44 起已显式关闭；换机迁移仍然可用
- App 每天自动往手机存储写一份备份，保留最近 7 份
- ⚠️ 但 WebView 的 IndexedDB 官方口径就是**临时数据** —— 系统空间紧张时会被回收
  （有真实的全量清空案例）。所以自动备份不等于保险，重要节点还是手动导出一份发出去

**Q5 · 换手机怎么办？**
旧手机「导出全部数据」，新手机「导入数据」。
