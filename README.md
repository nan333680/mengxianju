# 梦弦居 · 使用说明

一个安卓 AI 伴侣 App。纯本地、无账号、自备 API Key 直连 DeepSeek。

支持多角色、世界书（角色组 / 单独角色两层）、长期记忆与滚动摘要、剧情时间线、
发图识图、联网搜索、描写控制（上限 × 驱动力双轴）、视角锁定、
Character Card V2 导入导出（JSON / PNG）、自动备份。

> 这份说明是按 v0.3.0 校准的。逐版改了什么看 [CHANGELOG.md](CHANGELOG.md)。

## 一、安装（一加 Ace 3 / ColorOS 16 / Android 16）

APK 在发布页下载：

https://github.com/nan333680/mengxianju/releases/latest

历史版本见同一个发布页。

1. 从发布页下载 APK 到手机
2. 用手机的文件管理器点开这个 APK
3. ColorOS 会拦截，按下面走：
   - 提示"未知来源"→ 去 **设置 → 应用 → 特殊应用权限 → 安装未知应用**，允许你正在用的文件管理器
   - 弹出"未经安全检测 / 可能存在风险"→ 选 **仍要安装**
   - 如果被"纯净模式"挡住 → 设置里临时关闭纯净模式
4. 装好后桌面会出现「梦弦居」图标

> ⚠️ 装不上时，最常见原因就是 ColorOS 的安全拦截，不是 APK 有问题。

## 二、首次配置

打开 App 后会看到一个默认角色已经建好，但**还不能聊天**，需要先填 API Key
（App 顶部会有引导条提示）：

1. 点右上角 **⚙ 设置**
2. 在「接口」里填入你的 DeepSeek API Key（`sk-` 开头）
3. 关掉设置，回到聊天页 → 开始聊

### 默认参数

| 项目 | 默认值 | 说明 |
|---|---|---|
| 对话模型 | `deepseek-flash` | V4.1-Flash，**自带看图能力** |
| 识图模型 | `deepseek-flash` | 同一个模型就够 |
| Base URL | `https://api.deepseek.com` | 不用改 |
| 推理强度 | `low` | 见下方说明 |
| 温度 | 1.0 | 低=沉稳，高=活泼 |

### 推理强度 off / low / high / max

- **off** — 完全关闭思考，回复最快（内部映射为接口的 `none`）
- **low** — 聊天推荐，略微思考
- **high / max** — 更聪明但明显变慢，日常聊天用不上

## 三、主要功能

### 角色
- 点左上角 **☰** 进角色列表，**＋** 新建角色
- 每个角色有：名字、头像、人设、开场白
- 角色列表里点 **✎** 编辑

### 聊天
- 底部 **🖼** 发图片 → 她看得懂（用 `deepseek-flash` 的视觉能力）
- 回复是流式打字机效果
- 生成中可点 **停止** 中断
- Enter 发送，Shift+Enter 换行
- **长按消息**可：复制文字 / 删除这条 / 重新生成（对最后一条她的回复可用）

### 表达方式（设置页）

| 设置项 | 说明 |
|---|---|
| **颜文字频率** | 关闭 / 偶尔 / 适中 / 经常 / 总是 |
| **颜文字风格** | 日式温和 / 日式可爱 / 中式 / 混合 |
| emoji 频率 | 独立控制 |
| 回复长度 | 很短 / 短 / 中等 / 长 |
| 分段发送 | 一条长回复拆成几条，更像真人 |
| 打字延迟 | 模拟真人打字速度 |
| 使用「……」表现迟疑 | 模拟犹豫 |

> **颜文字频率不是简单塞提示词**：程序会统计最近 8 条消息的实际使用率，和目标频率做负反馈调节，避免她一会儿狂发一会儿完全不发。

### 记忆
- **长期记忆**开关打开后，会自动把久远的对话总结成要点记住
- **查看 / 编辑她记得的事** → 能手动增删

### 数据
- **导出全部数据** → 备份角色和聊天记录（不含 API Key）
- **导入数据** → 恢复
- 清空记录 / 清空全部数据

## 四、常见问题

**Q：发消息没反应 / 报错？**
A：先检查设置里的 API Key 填了没、账户有没有余额。

**Q：她说的话不像键山雏？**
A：进角色编辑，改「人设」那一段。写得越具体，演得越准。

**Q：想要完全不要颜文字？**
A：设置 → 表达方式 → 颜文字频率选 **关闭**（角色编辑里没单独设置的话，全局控制所有角色）。

**Q：聊天记录存哪？**
A：存在手机本地（IndexedDB），不上传任何服务器。卸载 App 会一起删掉，重要的话先导出。

系统云备份（Google Drive / 厂商云）从 v1.21.44 起已显式关闭；换机迁移仍然可用。
App 每天自动往手机存储写一份备份，保留最近 7 份。

⚠️ 但 WebView 的 IndexedDB 官方口径就是**临时数据** —— 系统空间紧张时会被回收
（有真实的全量清空案例）。所以自动备份不等于保险，重要节点还是手动导出一份发出去。

**Q：换手机怎么办？**
A：旧手机「导出全部数据」，新手机「导入数据」。

## 七、技术说明

- 纯前端实现，无自建后端；API Key 存在手机本地，直连 DeepSeek 官方接口
- 打包方式：Capacitor 8.5.2 + WebView
- 目标：compileSdk 36 / targetSdk 36 / minSdk 24（覆盖 Android 7.0+）

### 重新构建

```powershell
powershell -ExecutionPolicy Bypass -File tools\build-apk.ps1
```

构建脚本会自动：同步 Web 资源 → 打签名 Release 包 → 校验版本号一致性 → 输出 APK。

跑全部回归（100+ 套 e2e 串行，约半小时）：

```powershell
powershell -ExecutionPolicy Bypass -File tools\run-regression.ps1
```
